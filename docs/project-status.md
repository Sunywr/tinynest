在「记一笔 → 分类管理」可新增两级收支分类、改名、排序和停用。停用的分类仍可查看、重新启用，并保留历史流水关联。

在「设置 → 家庭成员档案」新增成员后，可在录入流水时选择关联成员。成员档案不授予登录权限。

在「记一笔」可搜索现有项目，也可新建项目并立即关联当前流水。「项目管理」提供资料编辑、收入与净支出汇总、归档和重新启用。归档项目保留历史流水关联。

「家庭账户 → 账户资料与流水」可改名、填写子类型和备注、指定归属成员。账户资料修改保留科目编号、余额与历史分录。此页也展示最近 100 笔账户分录净变动。

新用户可注册并凭邀请码申请加入家庭。家庭内用户可为未绑定的成员档案生成 48 小时有效的邀请码，也可指定新登录名。管理员审批通过后将账号绑定到该档案，用户即可登录。成员可使用本家庭账本，账号管理和审计日志仅管理员可访问。停用时撤销已有会话。细粒度权限仍待实施。
