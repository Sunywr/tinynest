在「记一笔 → 分类管理」可新增两级收支分类、改名、排序和停用。停用的分类仍可查看、重新启用，并保留历史流水关联。

点击「记账流水、家庭账户、信用账单、分期与负债、投资」时，页面先展示已创建项目的列表（流水、账户、信用工具与账单、负债与分期合同、持仓与分红记录），表单不再直接铺陈；点击「＋ 记一笔 / ＋ 新建账户 / ＋ 新增信用工具 / ＋ 新建固定负债 / ＋ 新建分期 / 买入 / 卖出 / 账户费率规则 / 分红与估值」等按钮才进入对应表单页，表单内「返回列表」可回到列表。设置页的邀请与成员表单同样经按钮进入。信用账单行「还款」、负债/分期合同行「期次/付款」、流水行「退款」会直达预填好的表单。

首页标题区有「＋ 记一笔」快速入口（含最近流水面板的「去记账 →」），一键直达记账表单；记账表单支持 Enter 键盘提交，提交前有账户/信用工具/分类的前端校验。常用分类、账户与支付工具以本机偏好（localStorage，仅 ID，不含金额等账务数据）记住，下次登录自动回填。

在「设置 → 家庭成员档案」新增成员后，可在录入流水时选择关联成员。成员档案不授予登录权限。

在「记一笔」可搜索现有项目，也可新建项目并立即关联当前流水。「项目管理」提供资料编辑、收入与净支出汇总、分类构成、最近 100 条拆分流水、归档和重新启用。归档项目保留历史流水关联。

「家庭账户 → 账户资料与流水」可改名、填写子类型和备注、指定归属成员。账户资料修改保留科目编号、余额与历史分录。此页也展示最近 100 笔账户分录净变动。

新用户可注册并凭邀请码申请加入家庭。家庭内用户可为未绑定的成员档案生成 48 小时有效的邀请码，也可指定新登录名。管理员审批通过后将账号绑定到该档案，用户即可登录。管理员也可在「有效邀请」撤销邀请码，关联的待审批申请同时失效。成员可使用本家庭账本，账号管理和审计日志仅管理员可访问。停用时撤销已有会话。细粒度权限仍待实施。

表单下拉框旁的「搜索」可按显示名称或文字筛选，清空关键词恢复完整列表。

「设置」显示当前会话所属家庭的名称与账本币种。
