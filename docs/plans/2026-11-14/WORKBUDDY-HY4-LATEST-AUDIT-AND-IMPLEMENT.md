### 3. 自动选择后续工作（只执行缺口）

**路径 A：V0.1.1 未完成**

补齐缺失的账单状态/信用额度、房贷保险合同 CRUD 和期次付款、分期部分付款时本金/费用拆分、自动每日到期调度、现金/信用负债转换、首页到期统计，保留已实现代码。重点复核同笔分期本金不能双计、调度不能把待办当已付；对新写接口添加事务、幂等、household 授权与审计。

**路径 B：V0.1.1 通过且 V0.1.2 有缺口**

按计划 M1～M4 实施投资与统计：

1. 账户级交易费率规则 CRUD：费率、最低佣金、适用方向/市场/产品、历史版本；单笔费用预览和人工覆盖，历史成交保留快照，手续费在后端定点计算。
2. 买入/卖出/加仓/减仓/清仓的成本与收益闭环：统一移动加权平均成本；买费计成本、卖费减净收入；股数/份额使用定点数；仓位成本和历史已实现收益不混淆；手动估值标注日期。
3. 分红：税前、已知税额或 `null`、到账账户、税后额，未知税额不得自动视为零；分红不重复计普通收入；支持历史分红列表及年度汇总。
4. 家庭资产与投资报表：现金资产（含证券可用现金）、持仓估值、房贷和信用负债、净资产；投资总收益 = 已实现 + 未实现 + 已知净分红（未知税额须提示不完整）；明确收益率分母和适用范围，不能称为年化。
5. PC Web/iPhone 响应式完整操作；按实有前端框架完善组件，不破坏 A「奶油团子」主题和用户原始图标。

**路径 C：以上功能已经完整**

### 4. 硬性账务验收

**投资示例（必须从 API/数据库产生）**：买入100股×10元费用5元 → 成本1005；再买100股×12元费用5元 → 200股、总成本2210；以13元卖出50股、卖费5元 → 已实现92.50、剩余成本1657.50；手动估值14元 → 未实现442.50；税前分红100元、税额10元 → 净分红90元；合计收益625元。若历史累计含费买入成本2210为分母，参考简单收益率为28.28%，不能写成年化。测试未填税额时不得默认税率为0。

**信用/房贷场景**：信用卡消费1000、还600、退300、再还100 → 最终负债0，无重复支出；房贷本金1500+利息500使用信用卡支付 → 房贷本金-1500、信用负债+2000、利息费用+500、现金不动，再还信用卡2000时不重复记费用。

**重复与安全**：同一幂等键并发20次只生成一笔业务；多家庭隔离测试包含读、写、账单、期次、统计及调度；分录借贷完全平衡；已入账记录只冲正不硬删；期初和跨月业务日 Asia/Shanghai；在测试 SQLite 中演练空库升级、重复迁移、备份及隔离恢复。
