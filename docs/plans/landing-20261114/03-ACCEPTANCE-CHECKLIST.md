# TinyNest 未登录首页与生产初始化收口：验收检查单

## 安全 P0

- [ ] 已初始化生产环境的所有公开页面都没有初始化/创建管理员入口。
- [ ] 直接请求后端 `/api/v1/setup` 不能创建第二个管理员。
- [ ] 首次离线部署仍可通过经过保护的一次性 token/运维流程完成初始化。
- [ ] token 不进入前端源码、日志、PWA 缓存、Git 历史。
- [ ] 登录 Secure Cookie、限流、CSRF、家庭范围过滤维持原有功能。

## 产品页面 P1

- [ ] 未登录访问 `/` 显示产品介绍，不默认显示表单。
- [ ] 「进入我的小家」才出现登录表单；已登录进入 Dashboard。
- [ ] Hero、功能卡片、页脚与现有真实实现一致，未完成能力标规划中。
- [ ] 公开页不使用真实家庭财务数据。
- [ ] 原始团子图标原文件不变；全站奶油团子风格一致。
- [ ] 退出、过期、后退、深链、异常登录无循环、无私人数据闪现。

## 动效、无障碍与移动端 P1

- [ ] Hero/弹窗/按钮/路由有轻量、稳定的动效。
- [ ] `prefers-reduced-motion` 禁用无限浮动及非必要动画。
- [ ] 模态框可键盘打开/关闭，焦点正确返回，合理 `aria` 标注。
- [ ] 390/768/1440px 布局没有溢出或无法点击的按钮。
- [ ] PWA 更新清除旧初始化页签；API 不被 SW 缓存。
- [ ] 浏览器 E2E 至少 16 项覆盖且结果可追溯。
- [ ] Go/Web 构建测试和 GitHub CI 对本次 SHA 真实全绿。

## 生产发布前

- [ ] 最新审计报告列出 commit SHA 和实际发现的风险。
- [ ] 独立测试数据库完成 setup/登录/登出/备份恢复演练。
- [ ] 已确认生产部署配置和 HTTPS/可信代理，无遗漏 API 初始化入口。
- [ ] 已在 iPhone Safari 实机验证 PWA（未实测不得勾选）。
- [ ] 未经批准不进行生产部署和数据库修改。
