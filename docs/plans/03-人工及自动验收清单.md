## A. 公开入口与安全

- [ ] 未登录首次访问 `/` 只有品牌 Landing，不显示登录表单。
- [ ] 登录 CTA 显示表单；键盘操作、焦点恢复和关闭行为正确。
- [ ] 登录失败、成功、会话过期、退出、直接访问私有路由无回归。
- [ ] 公开导航中不存在初始化页签/创建管理员入口；旧 PWA 缓存更新后也不存在。
- [ ] 已初始化测试库 direct `/api/v1/setup` 不会创建第二个管理员。
- [ ] 空 token/错误 token 的未初始化库拒绝 setup（仅隔离环境执行）。
- [ ] 生产代理 Cookie Secure/HttpOnly/SameSite、CSRF、登录限流、household 隔离继续通过。
- [ ] Landing 和离线壳绝不包含私人财务数据，Service Worker 不缓存 `/api`。
