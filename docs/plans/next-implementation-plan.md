## 换机后从这里开始

1. 在另一台 PC 打开仓库，按根目录 `AGENTS.md` 核对工作树、保留已有改动并同步 `origin/main`。从同步后的基线开任务分支。按 [开发说明](../DEVELOPMENT.md) 配置 Go、Node 和隔离测试库。
2. 以实际 checkout 的 SHA 检查源码和 CI。交接基线的 [CI](https://github.com/Sunywr/tinynest/actions/runs/43719525975) 已通过 Go 测试与 race、Web 构建、Chromium E2E 和临时 MySQL Unix socket 恢复。流水分页、调度失败重试、家庭三级角色、投资费率预览和家庭资产构成已有实现。
3. 先处理下方缺陷和契约校准。每项缺陷先写失败测试，再修复并跑全量回归。账务和权限变更须继续保持 SQL 层家庭隔离、整数分、分录不可变和上海业务日期。

## 删除操作

- [x] 家庭账户可从管理列表删除。删除后退出首页账户列表和记账选项，已入账余额、分录和报表影响继续保留。
- [x] 项目和分类可从管理列表删除，保留历史流水关联。一级分类删除前须先删除其子分类。
- [x] 支持删除未产生账务记录的信用工具。若已有账单、交易或分录，删除返回 409，仍可停用。
- [x] 持仓可删除最近一条手工估值。删除后使用上一条估值，无剩余估值时按现有未估值口径展示；持仓成本和分红沿用原分录。
- [x] 信用账单可查看还款历史并冲正误录还款。冲正恢复现金余额、账单应还及待付提醒。
- [x] 零余额账单可归档和恢复，保留消费、退款、还款及转分期引用。补录或冲正导致余额变化时自动回到普通列表。
- [x] 未入账本金且无付款历史的固定负债可删除，删除同步取消期次、移除待支付提醒。
- [x] 未付款、未退款的手工分期可撤销。按原入账日冲正，保留合同历史并取消待付期次。
- [x] 无付款历史的固定负债可撤销误录的期初本金。按原入账日冲正，保留合同历史并取消待付期次。
- [x] 未付款的信用账单转分期可撤销。恢复原账单应还和待付提醒，保留原消费及还款历史。
- [x] 误录的分期期次付款可冲正。信用渠道回写原账单。付款全部冲正且无退款时可继续撤销合同。
- [x] 固定负债付款可按原日撤销，所有付款均按原日撤销后可继续撤销合同。旧版跨日处理的付款仍需单独核对。
- [x] 用户界面用「撤销」「付款计划」「刷新待付款」等表述，账单和账户等主要状态展示中文。
- [x] 误录分期退款可撤销，原现金账户或信用账单同步更正。有效退款和付款均撤销后，合同可继续撤销。
- [x] 撤销已用于减免付款的退款。撤销后按「最近减免优先、同期次本金优先」自动恢复各期本金与手续费并补回待付提醒，后续实付金额与已入账分录保持不变；减免来自提前结清或调整记录与计划不一致时返回 409 拒绝。
- [x] 误录分红可按原到账日期冲正，保留原记录并更新现金流、持仓净分红和年度汇总。
- [x] 同一资产最后入账且顺序明确的买入或卖出可冲正。恢复资金、移动加权成本与已实现收益，保留成交历史。
- [ ] 早期投资成交的更正。核对后续卖出的持仓成本和已实现收益重算方案。
- [x] 成员档案支持删除未关联的记录，保留已绑定登录、有邀请历史或已关联账务的档案。

## 剩余实施顺序

生产版本 `6f42b1e` 已通过 Windows MySQL 8 的 19 项 TCP 回归及 [Linux CI](https://github.com/Sunywr/tinynest/actions/runs/44046088382) 的 Unix socket、备份恢复与浏览器回归。

1. 已完成。删除与撤销候选已通过 SQLite、MySQL、浏览器和生产冒烟，发布版本为 `6f42b1e`。
2. 已完成。撤销被减免占用的退款时，按最近减免优先（同一毫秒提交的减免按期次号大者优先）自动恢复期次义务，恢复金额在同一事件内本金优先于手续费；后续实付、已入账分录与负债科目不动，恢复动作写入 `installment_adjustments`（`restore_for_refund_reversal`）并恢复待付提醒。减免来自提前结清、或调整历史与计划对不上（重放校验失败）时仍返回 409。
3. 处理早期投资成交更正。先确定成交顺序与重算边界，再覆盖后续卖出的移动加权成本、已实现收益和原历史分录的更正链。

当前候选已发布。完成剩余删除与撤销计划预计还需两轮。下列产品决策如果全部纳入，确认后预计再加一至两轮。生产现场验收可与发布并行，完成时间取决于设备、测试账号及备份访问条件。

## 等待决策

- **单账户权限。** 当前权限按家庭角色划分。先确认可见与可写范围、转账涉及两个账户时的授权、受限账户的汇总口径和既有成员的兼容规则。
- **分期分录日期。** 当前使用首期到期日。确认是否改用消费发生日，并明确跨月快照及历史分录处理。既有十项确认见 [账务决策台账](../reviews/v0.1-accounting-decisions.md)。
- **投资费率体验。** 费率是否增加停用状态、费用预览是否随输入自动刷新，均为待定产品选项。停用如获确认，须保留交易费率快照并覆盖 SQLite 和 MySQL。
