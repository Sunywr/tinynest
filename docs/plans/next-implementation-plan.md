# TinyNest 待实施计划

交接日期 2026-11-15，核对基线为 `main` 的 `e89d3fa`。本页是继续开发的入口。产品设计和原始范围见 [V0.1 核心账本计划](../plan-v0.1.md)，历史验证见 [发布候选复核](../reviews/rc-readiness.md)。

## 换机后从这里开始

1. 在另一台 PC 打开仓库，按根目录 `AGENTS.md` 核对工作树、保留已有改动并同步 `origin/main`。从同步后的基线开任务分支。按 [开发说明](../DEVELOPMENT.md) 配置 Go、Node 和隔离测试库。
2. 以实际 checkout 的 SHA 检查源码和 CI。交接基线的 [CI](https://github.com/Sunywr/tinynest/actions/runs/43719525975) 已通过 Go 测试与 race、Web 构建、Chromium E2E 和临时 MySQL Unix socket 恢复。流水分页、调度失败重试、家庭三级角色、投资费率预览和家庭资产构成已有实现。
3. 先处理下方缺陷和契约校准。每项缺陷先写失败测试，再修复并跑全量回归。账务和权限变更须继续保持 SQL 层家庭隔离、整数分、分录不可变和上海业务日期。

- [x] **复核并修正信用额度与账单状态。** 列表和详情已根据上海业务日及应还、实还金额动态派生账单状态。修正未配置额度的负债占用已配置工具的汇总可用额度及使用率。现有回归覆盖退款、部分还款、跨周期和家庭隔离。

## 删除操作

- [x] 家庭账户可从管理列表删除。删除后退出首页账户列表和记账选项，已入账余额、分录和报表影响继续保留。
- [x] 项目和分类可从管理列表删除，保留历史流水关联。一级分类删除前须先删除其子分类。
- [x] 支持删除未产生账务记录的信用工具。若已有账单、交易或分录，删除返回 409，仍可停用。
- [ ] 逐项设计账单、负债、分期、投资记录和成员档案的删除操作。核对历史引用、余额和履约影响，覆盖权限、重复提交与账务回归。

## 等待决策

- **单账户权限。** 当前权限按家庭角色划分。先确认可见与可写范围、转账涉及两个账户时的授权、受限账户的汇总口径和既有成员的兼容规则。
- **分期分录日期。** 当前使用首期到期日。确认是否改用消费发生日，并明确跨月快照及历史分录处理。既有十项确认见 [账务决策台账](../reviews/v0.1-accounting-decisions.md)。
- **投资费率体验。** 费率是否增加停用状态、费用预览是否随输入自动刷新，均为待定产品选项。停用如获确认，须保留交易费率快照并覆盖 SQLite 和 MySQL。
