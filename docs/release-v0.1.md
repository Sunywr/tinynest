# TinyNest V0.1 发布候选说明

2026-11-15 · 当前为开发候选，发布门禁待通过。

## 已交付

- 家庭账本采用整数分和复式记账，已入账记录保留历史并通过冲正纠错。支持现金收支、账户转账、退款、成员和项目关联。流水可按日期和类型筛选与分页。
- 信用工具支持消费归账、还款、退款和转分期。固定负债与分期支持期次、部分付款、提前结清及到期待办。
- 投资支持买卖、账户费率、持仓成本、分红和手工估值。首页分别展示收支、现金流与负债到期口径，并提供净资产汇总。
- 家庭支持邀请、管理员审批、可记账和只读角色。浏览器端支持 PWA 安装资源与离线应用壳。

## 已知限制

- 单账户权限待定义。导入导出、实时行情和自动账单同步留待后续版本。
- 当前候选的远端 Linux MySQL Unix socket 与备份恢复演练失败。生产备份隔离恢复、异地副本、生产并发性能与 iPhone Safari 实机 PWA 待验收。
- 到期待办自动运行失败后重试一次。数据库不可写时从服务日志查看失败。账务测试和恢复演练使用隔离环境及合成数据。

账务口径、验证结果与发布门禁分别见[决策台账](reviews/v0.1-accounting-decisions.md)、[发布候选复核](reviews/rc-readiness.md)和[下一轮待办](reviews/next-iteration-backlog.md)。
