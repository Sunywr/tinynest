## 4. 环境限制（如实标注，不冒领通过）

- `go mod tidy -diff` 在 Windows 上因 `core.autocrlf=true`，工作区 `go.sum` 为 CRLF，而 Go 生成的期望文件为 LF，故 `-diff` 报出全文件行尾差异并退出 1。**逐行内容完全一致，非依赖或代码缺陷**。CI 在 Linux 上 checkout 为 LF，本项标 `CI_UNVERIFIED`（未获 push 授权，不擅自推送触发 Actions）。
- 本机无 `gcc`，`go test -race` 标 `UNVERIFIED`（沿用 V0.1 已知限制）。
- 生产 HTTPS 双服务器、iPhone Safari 实机 PWA 标 `UNVERIFIED`；本轮不部署、不录入真实财务数据。
