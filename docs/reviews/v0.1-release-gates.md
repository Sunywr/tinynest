## 两套门禁的关系

```
功能分支修复完成
      │
      ├─ 门禁 A（工程）── MERGE_READY ──> 可合并 main，标记为「V0.1 开发基线」
      │                                      │
      │                                      ├─ 仍禁止：部署生产
      │                                      └─ 仍禁止：录入真实家庭财务数据
      │
      └─ 门禁 B（生产）── NO ──> 必须补齐 B1～B14 才可 PRODUCTION_READY
```

- 门禁 A 通过**不代表** V0.1 正式发布，也不代表账务口径已定稿。
- 任何「V0.1 发布完成 / 可直接用于真实记账」的表述在当前状态下都是虚假声明。
- 本轮未执行任何 merge / push / 部署动作；全部结论等待用户复核。
