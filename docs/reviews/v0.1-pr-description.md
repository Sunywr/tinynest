## 摘要

本 PR 在 Phase 0 工程骨架上交付 V0.1 家庭账本主体，并在首次合并前专项审查后修复全部已发现的 P0/P1 阻断缺陷：

- **账务内核**：复式记账（整数分、借贷平衡、冲正不删原分录）、7 个版本化 SQLite 迁移、真实持久化；收支/转账/退款、信用账单、分期、投资、首页三套统计口径。
- **本轮安全修复**：
  - `/api/v1/setup` 增加一次性 Bootstrap Token（fail closed、常量时间比较、并发只允许一次 201、初始化后 409）。
  - 所有财务聚合 SQL 下推 `household_id`，到期任务按父合同过滤，`biz_key` 改为家庭作用域。
  - 业务日期统一 Asia/Shanghai（可注入 Clock），审计/会话时间戳仍 UTC。
  - 会话 Cookie `Secure` 由 `TINYNEST_COOKIE_SECURE` 显式配置，只采信 `TINYNEST_TRUSTED_PROXIES` 声明的反代来源。
  - 登录失败限流（principal + IP 两级 bucket、有界冷却、429 + `Retry-After`、审计脱敏）。
- **文档与仓库卫生**：规范/架构/API 契约同步到 V0.1 现状（逐路由 `IMPLEMENTED`/`PARTIAL`/`PLANNED`）；`go mod tidy`；删除重复计划；本地过程记录移出 PR；systemd 模板与迁移版本探测修正；新增 GitHub Actions CI。
- **Vue 前端**：全真实 API 界面；初始化表单增加一次性令牌输入（不存浏览器）；PWA manifest / SW / 图标更新。
